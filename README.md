# 분실물 감지 AI 시스템 (AI Lost & Found)

고정 웹캠으로 공간을 감시하다가 **새로 놓인 물건을 자동 감지**하고, 멀티모달 AI(GPT / Gemini)로 **무엇인지 식별**한 뒤, 분류에 따라 **폐기 기한**(귀중품 90일 · 일반 60일 · 음식 1일)을 부여합니다. 기한이 되면 **관리자에게 이메일 알림**을 보내고, 물건을 누가 가져가면 **자동으로 '회수됨' 처리**합니다. 모든 현황과 조작은 Apple Human Interface Guidelines를 참고해 만든 **관리자 웹**에서 할 수 있습니다.

## 동작 원리

```
웹캠 ──▶ 움직임 감지 ──▶ 움직임 멈춤 + 3초 안정화 ──▶ 기준 화면과 비교
                                                       ├─ 새로 생긴 영역 → 사진 크롭 → AI 식별 → 등록 + 기한 부여
                                                       └─ 등록된 물건 자리가 비었으면 → '회수됨' 처리
백그라운드(1분마다) ──▶ 폐기 기한 검사 ──▶ 기한 임박(D-3)/도래 시 관리자 메일 발송
```

- **움직임 감지**: 연속 프레임 차이(가우시안 블러 + 임계값). 사람이 지나가는 동안은 분석하지 않고, 화면이 다시 안정된 뒤에만 장면을 비교하므로 사람 자체를 물건으로 등록하지 않습니다.
- **등장/회수 구분**: 변화 영역의 엣지 밀도 비교(생긴 것 vs 치워진 것) + 등록 물체의 템플릿 매칭(아직 그 자리에 있는지).
- **AI 식별**: 감지 즉시 등록하고 AI 분석은 비동기로 수행 → 카메라가 멈추지 않습니다. AI가 "사람/그림자"로 판단하면 등록을 자동 취소합니다. API 키가 없으면 **mock 모드**로 동작해 키 없이도 전체 시연이 가능합니다.
- **조명 변화 대응**: 화면 대부분이 한꺼번에 바뀌면(소등/카메라 이동) 물건 등록 없이 기준 화면만 갱신합니다.

## 실행 방법

### 1. 준비물

- Python 3.10 이상
- 웹캠 (없어도 동영상 파일로 시연 가능)
- (선택) OpenAI 또는 Gemini API 키 — 없으면 mock 모드
- (선택) 메일 알림용 Gmail 계정 + 앱 비밀번호

### 2. 설치

```bash
git clone <이 저장소>
cd AI-based-lost-item-management-project

python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
```

### 3. 설정 (선택)

```bash
# 예시 파일을 복사해 채워 넣기 (건너뛰어도 실행됨 — 웹 설정 페이지에서도 전부 변경 가능)
cp .env.example .env
```

`.env`의 주요 항목:

| 항목 | 설명 |
|---|---|
| `CAMERA_SOURCE` | 웹캠 번호(`0`, `1`, …) 또는 동영상 파일 경로 |
| `OPENAI_API_KEY` / `GEMINI_API_KEY` | 멀티모달 AI 키 (둘 중 하나면 충분, 없으면 mock) |
| `ADMIN_EMAIL` | 알림을 받을 관리자 메일 주소 |
| `SMTP_USER` / `SMTP_PASSWORD` | 발신용 Gmail 주소 / **앱 비밀번호 16자리** |

> **Gmail 앱 비밀번호 발급**: Google 계정 → 보안 → 2단계 인증 켜기 → "앱 비밀번호" 검색 → 발급된 16자리를 `SMTP_PASSWORD`에 입력. (일반 로그인 비밀번호는 동작하지 않습니다.)

### 4. 실행

```bash
python run.py
```

브라우저에서 **http://localhost:8000** 접속 → 관리자 웹이 열립니다.
설정은 웹의 [설정] 탭에서 언제든 바꿀 수 있고, DB에 저장되어 `.env`보다 우선합니다.

### 5. 웹캠 없이 시연하기 (합성 데모 영상)

```bash
# "빈 책상 → 지갑을 놓고 감 → 잠시 후 가져감" 30초 영상 생성
python scripts/make_demo_video.py demo.mp4

# 그 영상을 카메라 소스로 실행 (영상은 자동 반복 재생됨)
# macOS/Linux:
CAMERA_SOURCE=demo.mp4 python run.py
# Windows (PowerShell):
$env:CAMERA_SOURCE="demo.mp4"; python run.py
```

등록 → 회수까지 전체 흐름이 화면에서 자동으로 반복됩니다.

### 자동 테스트

```bash
python scripts/run_e2e_test.py
```

합성 영상으로 서버를 띄워 *물체 등록 감지 → 회수 감지 → 관리 API → 폐기 스케줄러*를 검증합니다 (16개 항목).

## 관리자 웹 기능

| 화면 | 기능 |
|---|---|
| **대시보드** | 실시간 카메라(감지 상태·물체 위치 오버레이), 보관/등록/폐기 대상/회수 통계, 최근 등록 목록, 감지 일시정지·기준 화면 초기화 |
| **분실물** | 상태·분류 필터, 검색, 사진 업로드로 수동 등록, 상세 모달(이름·분류·기한·설명 수정, 회수/폐기/재보관 처리, AI 재분석, 삭제) |
| **이벤트 로그** | 감지·식별·회수·메일 발송 등 모든 이력 |
| **설정** | AI 공급자·API 키, 분류별 보관 기간, 메일(SMTP)·테스트 발송, 카메라·감지 민감도, 폐기 검사 즉시 실행 |

다크 모드를 지원하며(우측 하단 토글), 모바일 화면에도 대응합니다.

## 시연 팁

- **카메라는 단단히 고정**하세요. 카메라가 흔들리면 화면 전체가 "변화"로 인식됩니다 (이 경우 시스템이 자동으로 기준만 갱신하고 오등록은 막습니다).
- 물건을 놓거나 가져간 뒤 **손을 화면 밖으로 완전히 빼고 3초** 기다리면 분석이 실행됩니다 (설정의 "안정화 대기"로 조절).
- 조명이 급격히 바뀐 직후에는 대시보드의 **[기준 초기화]** 버튼을 한 번 눌러 주면 깔끔합니다.
- 폐기 알림 시연: 물품 상세에서 폐기 기한을 어제로 수정 → 설정의 **[지금 검사 실행]** → 관리자 메일로 알림이 발송됩니다.
- 오탐이 많으면 설정에서 "움직임 민감도"와 "최소 물체 크기 비율"을 올리세요.

## 기술 스택 / 구조

FastAPI + OpenCV + SQLite + 바닐라 JS. AI는 SDK 없이 REST로 직접 호출(OpenAI `gpt-4o-mini`, Gemini `gemini-2.0-flash` — 설정으로 변경 가능).

```
app/
├── main.py            # FastAPI 조립, 스레드 기동
├── config.py          # 설정 (DB > .env > 기본값)
├── database.py        # SQLite 저장소
├── vision/
│   ├── camera.py      # 캡처 스레드 (자동 재연결, 파일 루프)
│   └── detector.py    # 모션 상태머신 + 장면 비교 (등장/회수)
├── ai/classifier.py   # GPT / Gemini / mock 물체 식별
├── services/
│   ├── items.py       # 물품 수명주기 (등록→식별→회수/폐기)
│   ├── scheduler.py   # 폐기 기한 검사 (1분 주기)
│   └── notifier.py    # SMTP 메일
├── api/routes.py      # REST API + MJPEG 스트림
└── static/            # 관리자 웹 (Apple HIG 스타일)
scripts/
├── make_demo_video.py # 합성 시연 영상 생성
└── run_e2e_test.py    # 엔드투엔드 자동 테스트
```

## 알려진 한계

- 물건을 **다른 위치로 옮기면** "회수 + 신규 등록"으로 기록됩니다 (동일성 추적은 하지 않음).
- 두 물건이 **겹쳐 놓이면** 하나로 등록될 수 있습니다.
- 트랙(물체 위치) 복원은 서버 재시작 시 **카메라 구도가 같다**는 가정 하에 동작합니다.
